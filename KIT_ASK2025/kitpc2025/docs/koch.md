제목: 별 찍기 - 눈송이
시간 제한: 2초
메모리 제한: 2048MB

저번 겨울 대한민국은 전국적으로 엄청난 양의 적설량을 자랑했다. 고분자 공학과 친구한테서 현미경을 빌려온 진호는 하늘에서 내려온 눈송이 하나를 확대해서 관찰했다. 눈송이 하나에는 수많은 눈 결정이 들어있었다.
눈 결정 하나를 관찰하고 나서 신기한 점을 발견헀다. 눈 결정은 확대를 해도 축소를 해도 같은 패턴을 가지고 있었다. 

주어지는 크기의 눈 결정을 찍어 보자. 1에서 8까지 크기 $N$이 주어진다.

1, 2, 3 크기의 눈 결정이 예제로 주어진다.

출력해야하는 결정의 크기가 크기 때문에 고속입출력을 사용한다.
C++ 코드의 경우
```cpp
ios_base::sync_with_stdio(false);
cin.tie(NULL);
cout.tie(NULL);
```
을 main 함수 맨 앞에 사용하고, 줄바꿈 문자도 std::endl 대신 "\n" 을 사용한다.

Python 코드의 경우 시간초과가 난다면 sys 모듈의 sys.stdout.write() 메서드를 사용하는 것을 권장한다.
