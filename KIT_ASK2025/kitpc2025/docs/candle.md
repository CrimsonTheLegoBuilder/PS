제목: 촛불과 촛불과 촛불과 그림자
시간 제한: 3초
메모리 제한: 1024MB

꼭짓점이 ($A_1$,$B_1$), ($A_2$,$B_2$), ···, ($A_N$,$B_N$)인 빨간색 볼록 $N$각형과, 각각 꼭짓점이 ($C_1$, $D_1$), ($C_2$, $D_2$),$\cdots$,($C_{M_k}$, $D_{M_k}$)인 파란색 볼록 $M_k$각형이 $K$개 있다. 

빨간색 볼록 다각형 내부에 모든 파란색 볼록 다각형들이 완전하게 포함된다. 또한 서로 다른 두 개의 파란색 다각형은 서로 겹치거나 만나지 않는다.

빨간색 볼록 다각형 내부이나, 파란색 볼록 다각형의 내부와 경계에 포함되지 않는 영역을 $S$라 하자. 

아래 그림과 같이, 영역 $S$의 한 점에 촛불을 설치하면 노랑색 영역이 밝아지고, 회색 영역에는 그림자가 생긴다.

노란 빛 촛불만 옮기며 노는 게 질린 진홍이는 빨강(Red), 초록(Green), 파랑(Blue) 빛이 나는 촛불을 하나씩 구해왔다.
빛의 합성의 원리에 따라 각각의 빛이 섞이면

빨강(Red) + 초록(Green) = 노랑(Yellow)

빨강(Red) + 파랑(Blue) = 마젠타(Magenta)

초록(Green) + 파랑(Blue) = 시안(Cyan)

빨강(Red) + 초록(Green) + 파랑(Blue) = 하양(White)

색으로 합성된다.

그리고 모든 빛이 닿지 않아 그림자가 생기는 영역은 검은색(Black)으로 표현할 수 있다.

빨간색 볼록 $N$각형과 $K$개의 파란색 볼록 $M_k$각형의 좌표, 그리고 빨강, 초록, 파란색 촛불의 위치가 주어질 때, 빨강, 초록, 파랑, 노랑, 마젠타, 시안, 하얀색 빛으로 빛나는 영역의 넓이를 구해보자.

이 때, 빨간색 $N$각형 외부에 있는 촛불은 관찰 대상에서 제외한다.

\textbf{단, 파란색 다각형 안에 있는 촛불은 관찰 대상이다.}

**입력**

첫 번째 줄에 빨간색 다각형의 꼭짓점 수 $N$이 주어진다. $(1 \le N \le 100)$

두 번째 줄부터 $N$개의 줄에 걸쳐 빨간색 다각형의 꼭짓점 정보를 나타내는 두 정수 좌표 $A_i$와 $B_i$가 반시계 방향으로 주어진다. $(-1\,000 \le A_i, B_i \le 1\,000)$

$N+2$번째 줄에 파란색 다각형의 총 개수를 나타내는 정수 $K$가 주어진다. $(1 \le K \le 33)$

이후 $K$개의 블록이 아래 형식으로 주어진다.
\begin{itemize}
  \item 블록의 첫 번째 줄에 $k$번째 파란색 다각형의 꼭짓점의 수 $M_k$가 주어진다. $(1 \le k \le K;\ 1 \le \sum{M_k} \le 100)$
  \item 다음 $M_k$개의 줄에 걸쳐 $k$번째 파란색 다각형의 꼭짓점 정보를 나타내는 두 정수 좌표 $C_{kj}$와 $D_{kj}$가 공백을 두고 주어진다. $(1 \le j \le M_k;\ -1\,000 \le C_{kj}, D_{kj} \le 1\,000)$
\end{itemize}

이어서 쿼리의 개수를 나타내는 정수 $Q$가 주어진다. $(1 \le Q \le 100)$

이후 $Q$개의 줄에 걸쳐 쿼리가 한 줄에 하나씩 주어진다. $(1 \le Q \le 100)$

쿼리마다 빨강, 초록, 파란색 촛불을 설치할 $3$개의 좌표를 나타내는 $6$개의 정수 $R_{qx}$,$R_{qy}$,$G_{qx}$,$G_{qy}$,$B_{qx}$,$B_{qy}$가 공백을 두고 주어진다. $(-1\,000 \le R_{qx}, R_{qy}, G_{qx}, G_{qy}, B_{qx}, B_{qy} \le 1\,000)$

모든 다각형 벽의 두께는 $0$으로 가정하며, 촛불이 다각형의 변 위에 놓여있는 상황은 주어지지 않는다.

각 촛불은 면적이 없는 점으로 가정한다. 다각형의 내부는 어떠한 촛불도 들어있지 않다면 검은색으로 가정한다.

\textbf{모든 쿼리는 서로 독립적이다.}


**출력**

각 쿼리마다 순서대로 한 줄에 실수 하나 씩 8줄에 빨강, 초록, 파랑, 노랑, 마젠타, 시안, 하양, 검정색 영역의 넓이를 출력한다.
